# БЫСТРЫЙ СТАРТ: сайт на GitHub Pages с телефона

## Шаг 1. Скачайте и распакуйте архив
1. Скачайте ZIP проекта на телефон.
2. В «Файлах»/«Проводнике» нажмите на ZIP → «Извлечь». Получится папка champions-mindset.

## Шаг 2. Создайте репозиторий на GitHub
1. В браузере откройте github.com и войдите (регистрация бесплатна).
2. «+» → «New repository». Имя — например champions-mindset. Public. Создайте.

## Шаг 3. Загрузите файлы через браузер
1. В репозитории: «uploading an existing file» (или «Add file» → «Upload files»).
2. ВАЖНО: загружайте СОДЕРЖИМОЕ папки (index.html, assets/, legal/, docs/, backend/...).
   Папку backend/ загружать на GitHub НЕ обязательно (см. ниже), но можно — секретов в ней нет.
3. «Commit changes».

## Шаг 4. Включите GitHub Pages
1. Settings → Pages.
2. Source: Deploy from a branch. Branch: main, папка: / (root). Сохраните.
3. Через 1–3 минуты сайт откроется по адресу:
   https://ВАШ_ЛОГИН.github.io/champions-mindset/

## Шаг 5. Проверьте
- Откройте сайт с телефона: меню, текст, фото, кнопки.
- Картинка или стиль не грузится? Проверьте, что папка assets загружена целиком,
  имена файлов — маленькими буквами.

## Что ВАЖНО понять
GitHub Pages — это только ВИТРИНА сайта. Оплата, база данных и автоматическая
выдача Telegram-доступа работают через отдельный сервер:
- docs/DEPLOYMENT.md — сервер backend
- docs/PAYMENTS_SETUP.md — оплата
- docs/TELEGRAM_SETUP.md — бот и канал

## Где менять настройки
- Цена, контакты, адрес сервера → assets/js/config.js (на GitHub кнопка «Edit»).
- Секреты (токены, ключи) — НИКОГДА не в config.js, только в backend/.env на сервере.
