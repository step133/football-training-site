# Безопасность: реализовано и проверить перед запуском

## Реализовано в коде
- Секреты только в переменных окружения backend (.env в .gitignore).
- Webhook проверяет сумму, валюту, статус и metadata.
- Идемпотентность: уникальный индекс по payment_id, повторный webhook игнорируется.
- Приглашения в Telegram одноразовые и ограничены по времени, создаются только сервером.
- Статус заказа проверяется на сервере, а не по параметру в URL.
- Rate-limit на создание заказов; CORS; валидация входных данных.
- Пароли не используются (настоящая авторизация появится вместе с серверным кабинетом).

## Проверить перед запуском
- Сменить Access-Control-Allow-Origin "*" на адрес вашего сайта в server.js.
- Убедиться, что репозиторий backend приватный.
- Заполнить юридические страницы и показать их юристу.
- HTTPS включён (Render и GitHub Pages дают его по умолчанию).

## Ограничения (честно)
- Проект не проходил независимый аудит безопасности.
- SQLite подходит для старта; при росте — PostgreSQL (Neon/Render) без смены кода запросов.
